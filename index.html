① 글꼴 파일 — 모든 예제가 이 글꼴을 함께 써요.

// src/font.ts
import {loadFont} from '@remotion/google-fonts/NotoSansKR';
export const {fontFamily: FONT} = loadFont();

② 등록 파일 — 예제 첫 줄 // frames=180 size=1280x720을 보고 빨간 숫자 3개만 맞춰 주세요.

// src/Root.tsx
import {Composition} from 'remotion';
import {Scene} from './Scene';

export const RemotionRoot = () => (
  <Composition id="Scene" component={Scene} durationInFrames={180} fps={30} width={1280} height={720} />
);

③ 재료 폴더 — 예제에 쓰는 연습용 상품 사진 6종·효과음 12종·배경음악은 함께 드린 remotion-70-examples.zip의 public 폴더를 내 프로젝트에 그대로 복사하면 됩니다. 70개를 한 번에 보려면 zip을 풀고 npm i → npm run dev.

④ 영상 파일로 뽑기: npx remotion render Scene out/my.mp4

효과음

효과음 넣는 법

효과음은 "몇 번째 프레임에, 어떤 소리를"만 정하면 됩니다. 예제 창의 효과음 탭에서 어울리는 소리를 골라 켜면 코드에 자동으로 들어가요. 새 예제(51~70번)와 03·21·22·31·32번에는 맨 위에 SFX 타이밍표가 이미 있어요. 아래 소리는 모두 직접 합성해서 저작권 걱정 없이 써도 됩니다. 눌러서 들어 보세요.

import {Audio, Sequence, staticFile} from 'remotion';

// 45번째 프레임(1.5초)에 '카칭' 소리를 80% 크기로
<Sequence from={45} layout="none">
  <Audio src={staticFile('sfx/cash.wav')} volume={0.8} />
</Sequence>

리모션 공식 효과음 패키지 @remotion/sfx(whoosh·ding·mouseClick·pageTurn 등)도 있어요. 단, 인터넷 밈 소리가 많이 섞여 있어 상업용 광고·강의에는 저작권을 확인하고 쓰세요.

AI로 확장

내 예제를 AI로 만드는 프롬프트 3종

Claude Code에서 npx remotion skills add로 공식 스킬을 설치한 뒤 붙여 넣으세요. 이 70개도 이 형식으로 만들었습니다.

1. 새 예제 만들기

src/Scene.tsx 파일을 새로 만들어줘.
주제: [예: 내 그림책 신간 홍보 15초 세로 쇼츠]
규칙:
1) 첫 줄에 // frames=숫자 size=가로x세로 주석
2) 바꿀 값(문구·색·숫자·시간·사진)은 맨 위 "── 여기만 바꾸면 돼요 ──" 아래 상수로 모으기
3) 효과음은 SFX 타이밍표(at·src·vol)로 만들고 public/sfx 폴더의 소리만 쓰기
4) import {FONT} from './font' 사용, export const Scene 으로 내보내기
5) 계산 줄마다 중학생도 알 수 있는 한국어 주석

2. 두 예제 섞기

51번(히어로 등장)의 제품 등장 방식과 54번(가격 쾅!)의 가격 도장을 합쳐서
새 Scene.tsx를 만들어줘. 제품은 public/book.png, 가격은 [15,000원].
두 예제의 상단 상수·SFX 타이밍표 형식은 그대로 유지해줘.

3. 내 브랜드로 일괄 변경

src/examples 안의 모든 예제에서 상단 상수의 색을
내 브랜드 색 [예: 메인 #2E7D6B, 보조 #F4C95D]으로 바꾸고,
font.ts 글꼴을 [예: Gowun Dodum]으로 바꿔줘.
